# 咖啡馆 NPC 开发记录

## 2026-09-30：场景与 Harness 首轮实现

本轮已建立真实场景和业务源码，并通过 MCP 验证规则模式下的真实 Godot／Python 联调、实体交付和跨重启记忆。下文先记录规则联调，随后记录配置密钥后的真实 DeepSeek 验收，两类证据分别列出。

### 实际基线与复用决定

目标平台为 Windows，当时的 MCP 会话确认引擎为 `4.7.2-stable (official)`。本节保留首次实现时的历史证据；当前工具链已改为 Godot MCP Native，配置与迁移验证见文末。

| 能力及可见验收 | 当前采用 | 自写的业务部分 |
| --- | --- | --- |
| 人物移动、绕障和真实到达回执 | `CharacterBody3D`、`NavigationAgent3D`、`NavigationRegion3D` | 固定锚点、速度、暂停及实际到达检查 |
| 跟随与俯视镜头 | `Camera3D`、`SpringArm3D` | 身份切换、输入和镜头切换 |
| 制饮、放杯、整理与注视 | `AnimationPlayer`、节点层级和插槽 | 有限动作映射、通道占用、同一杯子的归属转移 |
| 入店与环境观察 | `Area3D`、物理射线 | 固定 ID、独立视听规则和 JSON 快照 |
| 前后端与模型请求 | `WebSocketPeer`、FastAPI WebSocket、HTTPX | `cafe3d.v1` 消息、动作回执、薄模型网关 |
| 目标、会话和记忆 | `asyncio.Queue`、Pydantic、`sqlite3` | 订单阶段、话题进度、玩家资料、承诺和三组 Prompt |

内置能力已覆盖本轮需要，因此暂不引入导航、相机、状态图、对话或向量检索插件；不建设通用工作流、数据库封装平台或测试运行器。Godot 主控真实空间与单步动作，Python 主控完整服务流程、战略和长期记忆。取消订单新增 `retrieve_cup` 原子动作，完整回收流程仍由 Python 编排。

依赖声明与 `api/uv.lock` 一致：FastAPI `0.115.12`、HTTPX `0.28.1`、Pydantic `2.11.7`、python-dotenv `1.1.0`、Uvicorn `0.34.3`、websockets `15.0.1`。Python 要求为 `>=3.11,<3.14`；本地虚拟环境配置记录 CPython `3.12.11`。`asyncio` 和 `sqlite3` 使用标准库，不另装实现。此处为文件核查，不代表后端测试结果。

当前模型配置为 DeepSeek `deepseek-flash`，地址 `https://api.deepseek.com`，通过 `/chat/completions` 调用；事件、战略、经历摘要复用同一模型。官方[更新说明](https://api-docs.deepseek.com/updates/)确认该模型 ID。配置不能替代账号及真实调用验证。

原始资料：Godot 4.7 [导航烘焙](https://docs.godotengine.org/en/4.7/tutorials/navigation/navigation_using_navigationmeshes.html)、[ResourceSaver](https://docs.godotengine.org/en/4.7/classes/class_resourcesaver.html)，[FastAPI WebSocket](https://fastapi.tiangolo.com/advanced/websockets/)，[Python asyncio.Queue](https://docs.python.org/3.12/library/asyncio-queue.html)。

### 正常启动与操作

从仓库根目录准备本地 `api/.env`（参考 `api/.env.example`），填写 `MODEL_API_KEY` 或 `DEEPSEEK_API_KEY`。默认 `NPC_MODE=model`；未配置 Key 会显示未配置，不自动切换规则。正常服务入口为：

```powershell
uv run --project api uvicorn cafe.main:app --app-dir api --host 127.0.0.1 --port 8765
```

后端使用 `8765`，Godot MCP Native 使用 `9080`。游戏连接 `ws://127.0.0.1:8765/ws/cafe`。当前主场景仍未配置；开发时通过 Native MCP `run_project(scene_path="res://scenes/cafe_world.tscn", allow_window=true)` 运行，正常手动体验可打开该场景后按 F6。开发验证仍严格遵守根 AGENTS 的 MCP 要求。完整接口说明见 [后端 README](../api/README.md)。

| 输入 | 当前行为 |
| --- | --- |
| WASD / Shift | 行走／加速 |
| 鼠标右键拖动 | 旋转跟随镜头 |
| Ctrl+1 / Ctrl+2 | 切换 A/B，另一角色仍留在原地 |
| Enter / Esc | 聚焦输入、发送／退出输入 |
| Tab | 切换发言目标 |
| E | 请求领取当前玩家的饮品，仍检查实际距离与订单状态 |
| F1 / F2 | 状态面板／俯视与跟随镜头 |

先走入咖啡馆再点单或交谈；右侧互动卡提供确认、接受、拒绝、暂停和继续。记忆页读取后端保存记录。数据库默认 `api/data/cafe.sqlite3`；正常重启保留长期资料，不恢复进行中的动作。
